# Windows Hosts Utility

Windows의 `hosts` 항목을 추가·조회·제거하는 도구입니다.

Windows 기본 hosts에는 보통 설명과 주석 처리된 예시만 있습니다. 등록된 항목이 없으면 IPv4 어댑터 또는 공유기에 설정된 DNS 서버로 주소를 조회합니다.

## 실행

- 한국어: `whu_kor.bat`
- English: `whu_eng.bat`

사용할 BAT 파일을 마우스 오른쪽 버튼으로 클릭한 뒤 **반드시 관리자 권한으로 실행**하세요. hosts를 수정·저장하려면 관리자 권한이 필요합니다.
관리자 권한이 아니면 재실행 안내 후 종료됩니다.

## 메뉴

1. **신규 추가**: 호스트 이름과 IP 주소를 입력합니다. 주석 달기는 선택 사항이며, 설명을 입력하거나 Enter로 생략한 뒤 확인 후 등록합니다.
2. **현재 내용 조회**: 등록 항목의 호스트 이름, IP, 설명을 확인합니다. 파일 원문 전체는 표시하지 않습니다.
3. **특정 항목 제거**: 현재 목록의 번호를 선택하고, 삭제할 IP·호스트 이름·설명이 맞는지 확인한 뒤 삭제합니다. 같은 줄의 다른 호스트 이름과 주석은 유지됩니다.
4. **사용 설명**: hosts 형식과 루프백 사용 예시를 확인합니다.
0. **종료**

## 입력 예시

```text
127.0.0.1 app.test # 로컬 개발용
```

`127.0.0.1`과 `::1`은 내 PC를 가리킵니다. 해당 주소와 포트에 로컬 서버가 없으면 접속할 수 없습니다. 다른 IP를 입력할 때는 연결하려는 서버의 주소인지 확인하세요.

호스트 이름만 입력하세요. `https://`, URL 경로, 포트, 와일드카드는 입력하지 않습니다.

여러 단계의 서브도메인도 입력할 수 있습니다.

```text
ex1.ex2.ex3.ex4.example.com
```

점으로 구분한 이름은 각각 최대 63자, 전체 호스트 이름은 최대 253자입니다. 설정은 입력한 이름에만 적용되며 다른 하위 도메인을 자동으로 포함하지 않습니다.

`#`부터 줄 끝까지는 설명 주석입니다. 같은 줄에 여러 호스트 이름이 있으면 같은 설명으로 표시됩니다. 주석이 없는 항목에는 "설명이 입력되지 않은 항목입니다."가 표시됩니다.

저장 후 DNS 캐시를 갱신하고 성공·실패를 안내합니다. 갱신에 성공하면 새 주소 조회부터 적용됩니다. 2번 조회 메뉴에서 확인하고, 반영되지 않으면 프로그램을 다시 실행하거나 PC를 재부팅하세요.
